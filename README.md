# Sehat — AI health insights from your blood report

Upload a blood report → AI extracts and normalizes the markers → you get plain-language
insights, a weighted health score, and a personalized nutrition / activity / lifestyle plan.
Family medical history (including deceased parents) feeds hereditary-risk reasoning.

> **India-first.** Data resident in `ap-south-1`. Built to respect the DPDP Act 2023
> (blood reports are *sensitive personal data*). This is **informational software, not
> medical advice** — every interpretation surfaces the raw lab value and a consult-your-doctor
> disclaimer.

---

## What this repo contains (MVP / Phase 1)

This is the **core loop**, built end-to-end and structured so the rest of the product bolts on:

| Implemented | Stubbed / integration-point (clearly marked `// TODO`) |
|---|---|
| Report upload API + storage abstraction (S3, local fallback) | Wearable sync (Apple/Fitbit/Garmin) |
| Marker extraction service (Textract + Comprehend Medical integration point, mock fallback) | Payments (Razorpay) + subscription tiers |
| Unit normalization (mg/dL ↔ mmol/L, etc.) | Family-alert / accountability notifications (Pinpoint/SNS) |
| **Real** weighted health-score algorithm | Nearby-food discovery (Amazon Location / Google Places) |
| AI insights + personalized plan (Bedrock Claude integration point, mock fallback) | Cognito-hosted auth UI (JWT middleware is wired, ready to swap) |
| Postgres schema, JWT auth middleware, error handling | |
| React frontend: upload → insights → score → plan | |

> The AI and OCR services run against **mock data out of the box** so you can run the whole
> flow with zero AWS credentials. Set the env vars in `.env` to switch to live AWS services.

## Run locally

```bash
# backend
cd backend
cp .env.example .env        # works as-is in MOCK mode
npm install
npm run dev                 # http://localhost:4000

# frontend (new terminal)
cd frontend
npm install
npm run dev                 # http://localhost:5173
```

With no AWS env vars set, the app runs fully in **MOCK_MODE**: a sample blood report is
"analyzed" so you can click through the whole experience.
